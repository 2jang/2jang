## 프로젝트 소개

음성이 실제 사람이 말한 것인지, 음성 합성이나 음성 복제로 만든 것인지 판정하는 한국어 딥페이크 음성 탐지 프로젝트입니다. 탐지 모델을 학습하고 평가하는 연구 파이프라인과, 학습한 모델로 음성 파일이나 마이크 소리를 판정해 보는 웹 데모로 이루어져 있습니다.

탐지 연구에서 주로 쓰는 벤치마크는 영어 데이터입니다. 그래서 한국어 음성으로 경량 모델 4종을 학습해, 탐지가 되는지와 데이터 구성에 따라 결과가 어떻게 달라지는지 실험했습니다. 서비스로 배포하지 않은 로컬 데모입니다.

## 주요 기능

<div class="feature-grid">

- **파일 업로드 판정** 음성 파일을 올리면 딥페이크 여부와 확률을 보여 줍니다.
- **3단계 판정** 확률이 0.4~0.6이면 진짜·가짜로 단정하지 않고 "판별 불확실"로 표시합니다.
- **구간별 분석** 4초 구간마다 판정해 의심 구간을 색으로 표시하고, 스펙트로그램을 함께 보여 줍니다.
- **모델 비교** 모델 10종 중 하나를 고르거나 6종을 동시에 실행해 판정, 확률, 추론 시간을 비교합니다.
- **입력 품질 경고** 소리가 찢어지거나 거의 무음이면 경고를 표시합니다.
- **실시간 감시** 말하는 동안 0.5초마다 판정해 그래프로 그립니다.

</div>

마이크 녹음과 실시간 감시는 시연용 기능입니다. 잡음이 섞이거나 녹음 경로가 바뀌면 판정이 크게 달라져서, 이 기능의 정확도는 주장하지 않습니다.

## 작업 범위

단독 프로젝트라 수집부터 웹 데모까지 모두 직접 했습니다. 모델 4종은 논문에 나온 구조를 구현한 것입니다.

- **데이터 파이프라인** 공개 데이터셋 5종을 수집해 16kHz로 변환하고 품질을 검사했습니다. 학습·검증용 고유 음성은 796,714개입니다.
- **모델 학습·평가** 경량 모델 4종(AASIST, SpecRNet, LCNN, RawNet2)을 데이터 조합별로 학습하고 평가했습니다.
- **웹 데모** FastAPI 추론 서버와 브라우저 화면을 만들었습니다. 파일 판정은 REST로, 실시간 감시는 WebSocket으로 처리합니다.

- **웹 데모** 서버가 올라온 음성을 16kHz로 바꾼 뒤 4초 구간(50% 겹침)마다 판정하고, 구간 평균으로 최종 판정을 냅니다.

## 사례 · 학습·검증 데이터 누수

- **문제** 결과를 다시 검토하다가 검증 데이터의 64.6%(112,956개 파일)가 학습 데이터에도 포함된 것을 발견했습니다. 검증 점수로 모델을 고르므로 선택 근거가 없어지는 문제였습니다.
- **원인** 따로 분할한 세 데이터 조합을 단순 병합했고, 조합끼리 같은 파일을 공유하고 있었습니다.
- **해결** 파일 796,714개를 하나로 합쳐 중복을 제거한 뒤 화자 단위로 다시 분할했습니다. 누수가 있으면 실패하는 검증 스크립트도 만들었습니다.
- **결과** 학습·검증 중복이 0개가 됐습니다. 재학습 전이라 수정 후 성능 수치는 기재하지 않았습니다.

## 한계

- 고친 분할로 다시 학습하지 않았습니다. 그래서 화면에 보이는 성능 수치는 최종 성능이 아닙니다.
- 아주 약한 잡음을 섞거나 녹음 경로가 바뀌면 판정이 크게 달라졌습니다.
- 서비스로 배포한 적이 없는 로컬 데모라 실사용자는 없습니다.
