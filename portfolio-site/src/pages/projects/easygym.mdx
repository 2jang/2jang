## 프로젝트 소개

동네 헬스장·필라테스·복싱장을 한곳에서 비교하고 회원권까지 결제하는 운동시설 중개 웹 서비스입니다. 운동할 곳을 찾는 사람은 종류와 지역으로 시설을 찾아 사진, 가격, 편의시설, 후기를 비교하고 회원권을 결제하거나 환불합니다. 시설을 운영하는 사업자는 자기 시설을 등록하고, 관리자는 회원·업체·신고·공지를 관리합니다.

처음 참여한 팀 프로젝트입니다. 팀 프로젝트가 끝난 뒤에는 혼자 라즈베리파이 서버에 배포해 유지보수했습니다.

## 담당 역할

- **팀 프로젝트 기간** 회원권 결제·환불 기능을 화면부터 DB 매퍼까지 담당했습니다. 지역 검색도 만들었습니다.
- **프로젝트 종료 후** 혼자 라즈베리파이 서버에 배포해 유지보수했습니다. GitHub Actions 빌드, LLM 챗봇(SSE 스트리밍), 로그인 캡차 서버 검증을 추가했습니다.
- **팀원 작업** 회원가입, 게시판, 공지, 마이페이지, 관리자 화면, 시설 상세 대부분.

## 사례 · Linux 서버에서 화면이 깨진 문제

- **문제** Windows에서 정상이던 화면이 Linux 서버에 배포하자 깨졌습니다.
- **원인** 경로와 확장자의 대소문자가 실제 파일 이름과 달랐습니다. Windows는 대소문자를 구분하지 않아 개발 중에는 드러나지 않았습니다.
- **해결** 대소문자를 무시하는 리소스 리졸버(244줄)를 구현했다가 같은 날 되돌리고, 근본 원인인 파일 162개의 이름을 수정했습니다.
